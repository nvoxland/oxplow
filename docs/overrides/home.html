// what oxplow gives you

Streams + worktrees

Each stream owns a branch and an isolated checkout. Agents on different streams cannot clobber each other.

Threads inside streams

Threads organize work and context. Each can have no agent session or several; one writer thread per stream owns worktree edits.

Durable work queue

Optional work items and epics keep plans durable. Activity is recorded without requiring task bookkeeping before edits or Stop.

Project wiki

Markdown notes with [[wikilinks]] to other notes, files, and commits — and cross-kind backlinks everywhere.

Local History

Turn-end and worktree snapshots preserve the record between commits. Inspect what changed and restore a file without disturbing the rest.

Change Analysis

Every commit, working tree, and agent effort gets a ranked summary: which files to look at first and why, per-function before/after metrics, co-change surprises, and duplication.

Collection, metrics, and dimensions

Collect and analyze what matters to your software. Built-in sources and your own extensions connect evidence and let you compare it across useful dimensions.

Your own tools and views

Have an agent build custom lenses, integrations, and workflows. Share useful extensions with your team, using the platform's shared services and action guardrails.
